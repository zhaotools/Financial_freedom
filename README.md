# :closed_book:【书籍推荐（共 16 本，适合入门、中级和进阶读者）】

## （入门）

:open_book: **[《富爸爸，穷爸爸》｜罗伯特·清崎，豆瓣评分：8.3](https://github.com/codeman008/Financial_freedom/blob/main/%E3%80%8A%E5%AF%8C%E7%88%B8%E7%88%B8%2C%E7%A9%B7%E7%88%B8%E7%88%B8%E3%80%8B.pdf)**

全球畅销的理财书，已被译为 50 多种语言，销量达数千万册。本书帮助你直观理解“富人思维”和“穷人思维”的差别，并建立对现金流与资产的基础认知。

:open_book:**[《小狗钱钱》｜博多·舍费尔，豆瓣评分：9.2](https://github.com/codeman008/Financial_freedom/blob/main/%E3%80%8A%E5%B0%8F%E7%8B%97%E9%92%B1%E9%92%B1%E3%80%8B.pdf)**

欧洲畅销理财书，通俗易懂地讲解如何从小开始管理金钱，而不是被金钱支配；如何像富人一样思考，正确认识和运用金钱；以及如何投资、找到积累财富的正确路径，更早实现财务自由。

:open_book:**[《穷查理宝典》｜彼得·考夫曼，豆瓣评分：8.6](https://github.com/codeman008/Financial_freedom/blob/main/%E3%80%8A%E7%A9%B7%E6%9F%A5%E7%90%86%E5%AE%9D%E5%85%B8%E3%80%8B.pdf)**

本书收录了查理·芒格完整的个人传记与投资理念，以及他过去 20 年的重要公开演讲和媒体访谈，涵盖投资评估流程、投资原则清单、投资建议等内容。

:open_book:**[《纳瓦尔宝典》｜埃里克·乔根森，豆瓣评分：8.4](https://github.com/codeman008/Financial_freedom/blob/main/%E3%80%8A%E7%BA%B3%E7%93%A6%E5%B0%94%E5%AE%9D%E5%85%B8%E3%80%8B.pdf)**

本书汇集了纳瓦尔在 Twitter、博客和访谈中的内容，于 2022 年出版，其中的观点在今天仍高度相关。赚钱不只是靠努力，更在于充分运用杠杆。

:open_book:**[《投资中最简单的事》｜邱国鹭，豆瓣评分：8.7](https://github.com/codeman008/Financial_freedom/blob/main/%E3%80%8A%E6%8A%95%E8%B5%84%E4%B8%AD%E6%9C%80%E7%AE%80%E5%8D%95%E7%9A%84%E4%BA%8B%E3%80%8B.pdf)**

一部难得的中国作者高质量理财书。书中提出了普通人也能理解的、简单且可执行的投资原则，例如“便宜是唯一硬道理”“数月亮，不数星星”。作者对于选股、择时与估值的观点，尤其贴合巴菲特的价值投资理念。

:open_book:**[《聪明的投资者》｜本杰明·格雷厄姆，豆瓣评分：8.8](https://github.com/codeman008/Financial_freedom/blob/main/%E3%80%8A%E8%81%AA%E6%98%8E%E7%9A%84%E6%8A%95%E8%B5%84%E8%80%85%E3%80%8B(%E7%BE%8E)%E6%9C%AC%E6%9D%B0%E6%98%8E%C2%B7%E6%A0%BC%E9%9B%B7%E5%8E%84%E5%A7%86.pdf)**

投资实战领域世界级、跨越世纪的经典，常被称为股市“圣经”。作者本杰明·格雷厄姆被誉为“华尔街之父”，也是巴菲特的老师。本书介绍了防御型与进取型投资者的资产组合策略。

:open_book:**[《指数基金投资指南》｜“银行螺丝钉”（雪球大 V），豆瓣评分：8.2](https://github.com/codeman008/Financial_freedom/blob/main/%E3%80%8A%E6%8C%87%E6%95%B0%E5%9F%BA%E9%87%91%E6%8A%95%E8%B5%84%E6%8C%87%E5%8D%97%E3%80%8B.pdf)**

聚焦低估值指数基金投资，系统讲解各类指数基金及有效的投资策略，教你“买什么、怎么买；卖什么、怎么卖”。

## （中级）

:open_book:**[《投资最重要的事》｜霍华德·马克斯，豆瓣评分：8.7](https://github.com/codeman008/Financial_freedom/blob/main/%E3%80%8A%E6%8A%95%E8%B5%84%E6%9C%80%E9%87%8D%E8%A6%81%E7%9A%84%E4%BA%8B%E3%80%8B.pdf)**

核心概念包括“第二层次思维”、价格与价值的关系、耐心等待机会及分散投资。它鼓励投资者成为“逆向投资者”，审慎判断市场周期，以大胆而谨慎的行动获取回报。

:open_book:**[《证券分析》｜本杰明·格雷厄姆，豆瓣评分：9.0](https://github.com/codeman008/Financial_freedom/blob/main/%E3%80%8A%E8%AF%81%E5%88%B8%E5%88%86%E6%9E%90%E3%80%8B%E6%9C%AC%E6%9D%B0%E6%98%8E%E2%80%A2%E6%A0%BC%E9%9B%B7%E5%8E%84%E5%A7%86.pdf)**

这是巴菲特大学课程中使用过的教材，系统讲解价值投资的实战方法，是经典中的经典，畅销至今已八十余年。

:open_book:**《股市投资进阶之道》｜李杰，豆瓣评分：8.7**

本书面向个人投资者，凝结了作者数十年的经验。核心内容分为三部分，分别对应投资之道、价值之源与估值之谜。

:open_book:**[《怎样选择成长股》｜菲利普·A·费舍尔，豆瓣评分：8.7](https://github.com/codeman008/Financial_freedom/blob/main/%E3%80%8A%E6%80%8E%E6%A0%B7%E9%80%89%E6%8B%A9%E6%88%90%E9%95%BF%E8%82%A1%E3%80%8B.pdf)**

作者菲利普·A·费舍尔被誉为“成长股投资之父”，也是华尔街最受尊敬和推崇的投资者之一。他的投资理念深刻影响了巴菲特、彼得·林奇等投资大师。

:open_book:**[《一本书读懂财报》（全新修订版）｜肖星，豆瓣评分：8.9](https://github.com/codeman008/Financial_freedom/blob/main/%E3%80%8A%E4%B8%80%E6%9C%AC%E4%B9%A6%E8%AF%BB%E6%87%82%E8%B4%A2%E6%8A%A5%EF%BC%88%E5%85%A8%E6%96%B0%E4%BF%AE%E8%AE%A2%E7%89%88%EF%BC%89%E3%80%8B.pdf)**

本书是解读和分析财务报表的经典著作，被读者誉为“我读过最好的财务入门书”。全书从如何阅读三大财务报表——资产负债表、利润表和现金流量表——以及它们之间的关系讲起。

## （进阶）

:open_book:**[《资产配置的艺术》｜大卫·M·达斯特，豆瓣评分：7.5](https://github.com/codeman008/Financial_freedom/blob/main/%E3%80%8A%E8%B5%84%E4%BA%A7%E9%85%8D%E7%BD%AE%E7%9A%84%E8%89%BA%E6%9C%AF(%E9%AB%98%E6%B8%85)%E3%80%8B.pdf)**

摩根士丹利投资集团创始人达斯特，被誉为“资产配置第一人”。本书系统讲解如何运用现代资产配置理念，组合股票、债券、现金、黄金和房地产等资产。

:open_book:**[《乌合之众：大众心理研究》｜古斯塔夫·勒庞，豆瓣评分：8.8](https://github.com/codeman008/Financial_freedom/blob/main/%E3%80%8A%E4%B9%8C%E5%90%88%E4%B9%8B%E4%BC%97%E3%80%8B%E5%8F%A4%E6%96%AF%E5%A1%94%E5%A4%AB%C2%B7%E5%8B%92%E5%BA%9E.pdf)**

社会心理学领域最具影响力的著作之一，精妙描绘群体心理。可将其群体心理理论应用于投资市场，避免随市场波动产生过度情绪，并防止冲动操作。

:open_book:**[《股票作手回忆录》｜埃德温·勒菲弗，豆瓣评分：8.8](https://github.com/codeman008/Financial_freedom/blob/main/%E3%80%8A%E8%82%A1%E7%A5%A8%E4%BD%9C%E6%89%8B%E5%9B%9E%E5%BF%86%E5%BD%95%E3%80%8B.pdf)**

《股票作手回忆录》是巴菲特指定的股市教材，记录了美国股市传奇人物杰西·利弗莫尔——“华尔街大空头”的投资生涯。

:open_book:**[《股市长线法宝》（第 5 版）｜杰里米·西格尔，豆瓣评分：8.6](https://github.com/codeman008/Financial_freedom/blob/main/%E3%80%8A%E8%82%A1%E5%B8%82%E9%95%BF%E7%BA%BF%E6%B3%95%E5%AE%9D%EF%BC%88%E5%8E%9F%E4%B9%A6%E7%AC%AC5%E7%89%88%EF%BC%89%E3%80%8B.pdf)**

《股市长线法宝》被列为有史以来十大最佳投资书籍之一。巴菲特曾评价：“这是一本无价的股市投资指南。投资者应认真研究杰里米·西格尔的新发现和新理念。”
